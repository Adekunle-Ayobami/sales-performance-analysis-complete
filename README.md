# Sales Performance Analysis

A personal portfolio project exploring monthly sales, product revenue,
customer-country performance and customer purchasing behaviour.

The project includes an Excel analysis workbook, SQL/MySQL scripts,
visualisations, findings and Power BI setup materials.
