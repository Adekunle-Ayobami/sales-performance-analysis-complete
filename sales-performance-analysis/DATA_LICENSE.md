# Dataset attribution

Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33

https://archive.ics.uci.edu/dataset/352/online+retail

Dataset licence: Creative Commons Attribution 4.0 International (CC BY 4.0).
https://creativecommons.org/licenses/by/4.0/

The original workbook is unchanged. Derived files remove exact duplicate rows, filter zero-quantity/nonpositive-price/invalid-key records, normalise text, derive revenue measures and aggregate transactions. No endorsement by the dataset creator is implied. Customer identifiers are the public dataset's existing identifiers.

The dataset licence does not automatically license the project's new code or prose. No separate code licence is selected for the user.
